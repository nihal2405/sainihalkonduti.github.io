An event-driven Azure pipeline that splits uploaded log files, extracts errors from each chunk, and stores them for querying.

01 / THE CHALLENGE

Make large logs manageable.

Large log files are difficult to inspect as a single unit. Error records need to be separated from the raw text and stored in a form that can be queried.

02 / THE SOLUTION

A deliberate path through the problem.

Uploading a file to the incoming container triggers a splitter. Each resulting chunk triggers a processor that parses log entries and inserts identified errors into Azure SQL.

PythonAzure FunctionsBlob StorageAzure SQLpyodbc
03 / BUILD DETAILS

The choices that shape the work.

01

Storage drives the workflow

Blob triggers connect incoming files to chunk creation, then chunk creation to processing.

02

Two focused functions

Splitting and parsing live in separate function directories so each step has a clear job.

03

A structured destination

The documented ErrorLogs schema stores a log identifier, original text, category, and creation time.

04 / OUTCOME

What the project delivers.

The repository provides both functions, sample log files, a database schema, and Azure setup instructions for recreating the pipeline.
